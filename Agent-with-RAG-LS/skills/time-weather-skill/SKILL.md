# Time and Weather Skill

## Description
Provides real-time local time and current weather conditions for any city globally using public Open-Meteo services without requiring API keys.

## Metadata
- **Name**: time_weather_tool
- **Function**: `env_tools.get_time_and_weather`
- **Trigger Queries**: 
  - What is the weather in Tokyo?
  - What time is it in London right now?
  - Show me temperature and time for New York.
  - What is the current time in Los Angeles or Hyderabad?

## Parameters
- `city` (string): The city name to lookup time and weather for.
